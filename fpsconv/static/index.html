truehdd --bed-conform: conform the Atmos bed to 7.1.2
About the flat 7.1 patchDEE 5.2.1 renders the legacy 7.1 of a Blu-ray DD+ Atmos encode as 5.1 + 2 height channels (MediaInfo: Tfl Tfr). The DD+ 7.1 patcher (LumaVistaLab, GPL-3.0) patches DEE's dee_audio_filter_ddp_atmos.dll for the run (backup, restore afterwards) so the encode is a real flat 7.1 with a Pro Logic IIx 5.1 core and Surround EX flag — MediaInfo: L R C LFE Ls Rs Lb Rb. Validated by its authors for DEE build 5.2.1-5994839 only (the DLL hash is checked before every run), so far with LAV Audio and Dolby Media Decoder on a synthetic master — listen to your first encode on your own AVR. Dolby says the height layout is by design and no DEE/DME version or setting changes it; this patch is the only known way to a real flat 7.1. Runs inside FPSConv's own Python — nothing else to install.
